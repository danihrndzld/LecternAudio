# CLAME

Unmodified `libmp3lame/` sources and `include/lame.h` from LAME 3.100
(https://lame.sourceforge.io, `lame-3.100.tar.gz`, SHA-256
`ddfe36cab873794038ae2c1210557ad34857a4b6bdc515785d1da9e175b1da1e`).
Licensed under the LGPL, see `COPYING` and `LICENSE`.

Left out: `mpglib_interface.c` (decoder), `vector/*.c` (SSE), `i386/` (NASM).
`config.h` is ours and replaces autoconf.
